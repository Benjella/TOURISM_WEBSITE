# 🌍 Tourism Guide Website

A responsive Tourism Guide Website built using **HTML, CSS, and JavaScript**. The website allows users to explore featured tourist destinations and search for places using a simple search functionality.

---

##  Live Demo

🔗 https://tourismwebsite-tau.vercel.app/

---

##  Project Overview

This project was developed to create a clean and user-friendly interface for exploring tourist attractions. Users can browse featured destinations and quickly search for available places.

---

##  Features

- 🔍 Search available tourist destinations
- 🖼️ Attractive destination cards with images
- 📱 Responsive layout
- 🎨 Clean and modern user interface
- ⚡ Lightweight and fast website

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
